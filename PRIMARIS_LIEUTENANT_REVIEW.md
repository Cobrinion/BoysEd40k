# Primaris Lieutenant — completion review

Current update: Phobos (+15) and Reiver (+10) bundles are now implemented,
reusing the existing weapon/blade values with conditional deployment/Terror
Troops rules. Exactly one of six bundles. See PRIMARIS_HQ_COMPLETION_REVIEW.md.

- New 75-point HQ with the established Boys Edition character profile: M7, WS5, BS5, T4, W2, A3, Ld9 and 3+.
- Uses the normal Primaris, grenade and shared weapon entries; no duplicate rifle, sword or shield profiles were made.
- One legal loadout is required: master-crafted auto bolt rifle and bolt pistol; master-crafted stalker bolt rifle and bolt pistol; master-crafted power sword and bolt pistol; or neo-volkite pistol, master-crafted power sword and shared Storm Shield.
- The Storm Shield option changes the displayed Save to 3+/3++ using the shared shield value.
- Tactical Precision is a GST rule and appears only in the Lieutenant's Special Rules characteristic.

Closest Firstborn comparison: junior Consul/Centurion-style command characters. The Lieutenant is deliberately below the 120-point Primaris Captain: one fewer Wound/Attack, lower WS/BS and a wound-reroll aura rather than Rites of Battle's hit-reroll role.
