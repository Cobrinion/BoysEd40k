# Primaris Apothecary — completion review

- New 80-point HQ using the project’s Primaris character scale: M7, T4, W2, A3, Ld9 and 3+.
- Source wargear is complete: absolvor bolt pistol, reductor pistol, frag grenades and krak grenades.
- Narthecium is the existing shared Feel No Pain (5+) profile; it was reused unchanged.
- Combat Restoratives is defined once in the GST and listed only in the Apothecary’s Special Rules characteristic.

Closest Firstborn comparison: Apothecary. The Primaris version trades the Firstborn attachment structure for an independent character card and D3 Wound restoration, while retaining the project’s Narthecium protection rather than importing a modern wound-based aura.
